# AI-Assisted Student Record and Result Management System

## Project Overview
This project is a Student Record and Result Management System developed using the C programming language. It helps manage student information and academic performance through a simple menu-driven application.

## Features
1. Add student records.
2. Search students using SAP ID.
3. Display all student records.
4. Calculate individual CGPA.
5. Calculate average CGPA by year.
6. Delete student records.
7. Sort students by SAP ID.
8. Sort students by name.
9. AI-assisted academic advisor that provides performance categories and suggestions.

## Student Information
The program stores:
- SAP ID
- Roll Number
- Name
- Phone Number
- Email
- Year
- Current Semester
- SGPA for completed semesters

## Academic Advisor
The academic advisor uses rule-based logic to categorize student performance:

| CGPA | Category |
|---|---|
| 9.00–10.00 | Excellent |
| 8.00–8.99 | Good |
| 6.00–7.99 | Needs Improvement |
| Below 6.00 | Immediate Attention |

It also provides a suggestion based on the student's CGPA.

## Technology Used
- Programming Language: C
- Header Files: `stdio.h`, `string.h`
- Platform: GitHub and OnlineGDB

## How to Run
1. Open the C source file.
2. Copy the code into a C compiler such as OnlineGDB.
3. Compile and run the program.
4. Select an option from the menu.
5. Follow the instructions displayed on the screen.

## Project Limitations
- Student records are stored in memory while the program is running.
- Records are not permanently saved after the program exits.
- The academic advisor uses rule-based logic and does not connect to an external AI service.
